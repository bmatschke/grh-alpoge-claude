# Review of residual

The common residue embedding handles the prime-to-coefficient-characteristic parts of both the matrix and character eigenvalues. The two type primes can play different roles in irreducibility and root exclusion. Integral descent uses the trace Gram matrix and a lifted primitive idempotent over the specified complete valuation ring.
