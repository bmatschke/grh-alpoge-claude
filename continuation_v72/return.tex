\section{Unramified coefficients and the two arithmetic hosts}

% BEGIN T72W1
\paragraph{T72W1. The three ends for the original unramified-coefficient datum.}
For the given $D,\iota,B$ take exactly the mark of E72G1.
E72G1 supplies its marking identities and the finite end,
E72G2 its original rank-three end for every embedding and every
tested matrix representation. R72Q1--3 supply its original rank-two
end for every admissible corner extension with trace zero at the
designated conjugation. In particular the weight is $2e+1$ and
the twist in the attached newform is $W\varepsilon^{-e}$. The
rank-two newform may depend on the point and the extension; none
of those choices enter the definition of the mark. This fills
$\mathrm{GdEnd}$, with its quantifier over the prolongation.

Now take an actual $D$ with coefficient ramification one and a
fixed $\iota$. Choose the prolongation used in UCE19 for this
datum. Apply the preceding result once. UCE12 returns finite
weight zero, UCE16 realizes each allowed entry map at an ordinary
point after integral scaling, and UCE17--18 return the automorphic
assertions along that scaling. In rank two the tested extension is
conjugated by the induced two-dimensional diagonal matrix. This
preserves its trace at conjugation and carries its values on the
sign kernel to the very corner of the rescaled point. The Hecke
polynomial assertion is invariant under that conjugation. Thus UCE19
gives $\mathrm{FinA}$, $\mathrm{AutB}$ and $\mathrm{LemW}$ for
one $g_1$ on the original coefficient datum, discharging the
whole obligation \texttt{AUT\_UNRAM\_COEF}.

\paragraph{T72W2. The one-character estimate and Case I.}
Use KIZ2's rank-three input with T72W1 in OCH30. The resulting
one-character statement supplies the finite list of traces for the
specified character before the later tests. With the same congruence
integer supplied by RNC16, PGK6 installs the full $\mathrm{PropGK}$.
Fix a target character $\chi$ and work at its field
$K_\chi=K_\star(p_K(\chi))$. KA3 applies the integer bound there
to give the two-prime $\mathrm{CorGK}$ estimate. KA1, KA2 and KA4
then sum over the required kernel orbits and return to the original
coefficients; the uniform constants precede the variable host.
This gives the Case I count on each original target.

\paragraph{T72W3. Installing the window and host on each target.}
For the common rank-four modular-support input use the already
supplied Case II support and QX10; YX2 installs the Case II count.
For the unrestricted target, use the supplied rank-four chain,
factor tower, descent and seed with this same promodularity input
in CJP1--3. For each datum choose the common embedding of
CJA1 before its points. For Case II use UX12 and for Case III use
CJP3. Applying CJA1--2 on both branches supplies the complete
symplectic image assertion: finiteness at weight zero, the block
obstruction and automorphy of the irreducible points. JX1 now applies
to its full input, with the cohomology, Ferrero--Washington and seed
inputs of the inherited certificate. This supplies the additional Case III count
used for arbitrary primitive Dirichlet characters. For the trivial
target, KA5 gives Case III vacuity by its order condition.

Use T72W2 for Case I and M72S4 for the guarded Case V bound.
The existing cohomological window assembly uses these counts
together with the two-primary and odd-minus estimates TW8 and
OB8, the previously supplied complementary cases and the
height estimates HV8--10. JX2 installs the case counts in
the height inequality; HV10 gives the pointwise height bound.
Use this on the common prime pair of QP22 in the window
construction. All are applied to the original fixed target. KA6 makes the specialization on the power-of-two
route explicit. This gives $\mathrm{VWinAt}(\chi,401)$ on
both routes. Finally HX1--4 give the original
$\mathrm{HostExW}(3/2,(G\chi).\mathrm{req})$ at that same $\chi$.
The constants and set of scales precede the individual scale;
the host and reference field may depend on the scale. Each chosen
host meets all the fields of the request at that scale. Further design, theta and global estimates must
still be supplied on the selected host.
