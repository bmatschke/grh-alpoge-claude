---------------------------

RF16: families [1,4,5,6,8,9,10,11,12,14,15,16,18,19] in the source order
of explicitConstants_parameterConditions_large. Together with the seven

This is the actual quantified conditional constructor, not merely a list
of asymptotic estimates. Its conclusion supplies a P for the SAME D,L,
with parConsts P = C.PK and P.CnW = C.P.CnW. All 111 named record fields
are accounted for: 23 constants, 23 positivity properties, 61 numerical
or exact-identity assertion fields furnished by the 21 families, and four
fields copied from the explicit HostArith hypothesis. The field map in
the provenance is checked against the names parsed from the pinned source.

The supplied data boundary is essential. D is an actual D7 and L an
actual SizeData₂ D satisfying Val C cD ch L. In particular, L already has
its three weight windows; the host already has its arithmetic prime data;
HCVal already gives its actual columns and root-of-unity character relation.

2. PN1: exact common data and uniformity
---------------------------------------
The literal SzRow definition is:

  for every epsilon with 0 < epsilon < 1/52,
  for every fixed C with Std C,
  there is cD0 such that for every cD >= cD0,
  there is ch0 such that for every ch >= ch0,
  there is x0 such that for every actual D and L : SizeData₂ D,
  if L.sc.eps = epsilon, x0 <= L.sc.x, and Val C cD ch L,
  then the stated proposition holds.

The x0 witness is chosen before D,L and cannot depend on either of them.
It can depend on epsilon, C, the previously chosen cD and ch. The host
scale J can vary with D,L; wherever it enters, HostConst gives 1<=J<=Cpde,
and all thresholds below use the fixed Cpde instead of J.

One can conjoin finitely many such assertions without changing this
order: first take the maximum of the cD thresholds; for a chosen cD take
the maximum of the ch thresholds; for chosen cD,ch take the maximum of
the x thresholds. The final D,L is held fixed when all conclusions are
applied. No choice of independent records is used to manufacture a join.

Notation throughout this report:

  n = D.R.n, f=2n, r=k+m-1, N=N_m=k+m(t+1),
  E=x^epsilon, ell=log x, delta=x^(-epsilon/8),
  b=exp(E), a=xb, X=exp(x^(epsilon/3)),
  b'=xb/X, w=b/(nX)=b'/(xn), X''=xnX=a/w,
  Delta=ceil_+(x^cD), H=2ceil_+(x^ch),
  S=4kDelta=L.Sc, eta=mH=L.etaSz, h0=H,
  d2=|T2|/n=L.de2, lambda=L.LaG.

Delta in this report is the scalar cloud spacing Delta_cl, not the
integral Weyl operator. We make no identification with the dual nabla.

Put

  Astar=n*t^2*(N+t)*E^2 + k*n^2*(S+t+E),
  lStar=m*b/Astar, lA=k*E/(m*d2),
  rS=m/2-1, Mrt=r+m*t=N-1, qSig=m.

The evenness and positivity fields in Ranks identify the natural rS with
the displayed real expression. Astar is strictly positive, as are m,b,d2;
the cancellations involving lStar below therefore have no zero case.

RF12 is reused for the actual bounds

  1<=n<=f<=x^3, 2<=m<=x, x^(1/4)<=m,
  k<=r<=x^5, 1<=t<=x^401, N<=x^402, 1<=E<=x.

  x^cD<=Delta<=2x^cD,
  x^ch<=H<=4x^ch,
  S<=8x^(cD+5)<=x^(cD+6),
  eta<=4x^(ch+1)<=x^(ch+3).

All eventual comparisons use RF11's proved exponential-series argument.
For fixed a<b, a nonnegative integer p, and a fixed A, the ratio
|A|x^a(log x)^p/x^b is at most

  |A|(p+1)! / ((b-a)^(p+1) log x)

once log x>=1. It therefore admits an explicit threshold for any positive

comparisons we use: fixed powers of x, with fixed coefficients, are
eventually below b,b',w uniformly for 1<=n<=x^3; b'*x^v<=b; and x^v*X<=b.
For w use log n<=3log x. Exponents may depend on cD,ch because they were
chosen before the eventual threshold. No floating-point test is used.
