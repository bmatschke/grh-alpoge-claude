SCOPE
-----
This proves the actual degree-realization join under the literal supplied
host, point-construction and numerical hypotheses. The route is
  provisional points/family -> GW5 -> host WOK
  -> reconstruct points for that one pair and all u0
  -> KitS's WallPt -> famOfKits -> ChosenWall -> ChosenWS.
It does not require CoverAll for a final family. It does require a point
constructor whose input ranges over every admissible pair. These are
different quantifiers: the constructor is invoked again after selection.

The source name HostWW includes further host/rank/prime assertions. They
are retained from the supplied host and are not proved here. Likewise,
KitCPW includes thick-set and chosen-bad-prime properties in addition to
the degree statement. We prove its actual kit and WallPt portion; the
other properties still require their named host/point suppliers. No Lean
source has been modified and no formal build has been performed.

EXACT UPSTREAM INTERFACE
-----------------------
Fix C, cD, ch and 0<eps<1/52, with Std C and C.GK.Nonneg (the latter
follows from the coefficient lower bounds in Std C). The Std fields are
also used directly for famOfKits's fixed and Cr assertions, independently
of NumAt. Let S be the supplied unbounded scale window
with fixed J, and let s be an allowed scale. For all sufficiently large
allowed s, the required host input is the literal HostExQW/HostGood data:
Ranks R, Host H, canonical auxiliary prime q0, RankVal, and H.CT2=C.CT2,
with any additional host predicate P retained. Let A=R.A, T=H.TT, n=R.n.
In particular n>0.

The supplied ObjC or ObjCP constructor must accept every pair a,b:A->Z
satisfying WinOK, every admissible injective word code of the prescribed
cardinality, and every u0<n. It returns an ACTUAL Pt C: D7, SizeData2,
ties ta and extra data xa, together with scale=s, Val, HostArith,
Pt.From H a b code u0, CanonInst and any point property Q being carried.
We do not replace Pt by a record containing only the fields used below.
The existing point's Extra includes ep_def and kapI_def; these are
substantive supplied fields of the actual point.

We also require the actual NumAt records used in famOfKits, both for the
temporary family and the reconstructed family. In the source they are
obtained from szRow_numAt. Its arithmetic and numerical supply is not
proved by this join. The constants of the temporary family must meet

uniform over its member index. An admissible initial pair and a code
must be supplied uniformly above a threshold; the source uses
exists_weights_in_windows and exists_injective_words. GW1 gives the

not silently derive RankVal-only host numerical bounds from that fact.

HW1. EXACT RELABELING AND THE TWO DIRECTIONS OF LOSS TRANSPORT
------------------------------------------------------------
1. Under Pt.From, identify the point's ranks with R. Both selected sets
have the same image under A.val. Since val is injective, the sets agree.
The same injectivity turns equality of the values of G.hP and hPH into
equality of the Frobenius steps themselves. Pt.From also equates q,d and
the underlying HostAx (heterogeneously before ranks are identified).
Therefore it preserves QS, the Artin integer, root-discriminant data,
and the prime-class function cls. These are actual identifications, not
an abstract claim that the two hosts have isomorphic counting models.

2. Write Delta=ceil_Nat(x^cD), h0=2ceil_Nat(x^ch). Val.Del_eq and the definition
of Sc give Sc=4k Delta, while Val.eta_eq gives eta=m h0. Thus the point
baseOfParams record equals the host baseOf record after relabeling:
  (R, s, q, d, cls, T, Sc, eta).
The host and point candidate conditions and their finite cutoff
p<ceil(X') agree term by term.

3. The source's universal deficit set is the set of real kappa>=0 such
that LPprime holds for EVERY appropriate unramified quadratic setting
and every dominant base weight at the prescribed depth, height and
error. In the two bases it is definitionally the same set. In particular
the coefficients cG=4Sc, DIf, c6f and tIf agree; the quantified settings
and weights are not narrowed to a particular field or chosen witness.
The point Extra.kapI_def says its kappaI is the infimum of this very set.
The arithmetic instance Arith.ins uses the same infimum by definition.
Consequently the kappaI functions agree. Equality of the sets suffices
here: the attainment theorem GJ1 is not needed to transport their infima.

4. Independently, CanonInst.1 says bs=Arith.bsH. Combined with the step
identity, this identifies the orbit representatives, good representatives,
pulled-back degree functions and local deficits. For arbitrary functions
a,b on A it gives the exact identity
  G.Sig(point,a,b,p)
   = Arith.Loc.Sig(hostBase, Arith.ins(hostBase,K,1),K,a,b,hPH,p).
The choice 1 for the last parameter of Arith.ins only changes its ep;
Sig uses bs and kappaI, so no equality of this ep with the point's actual
ep is asserted or needed here. In particular CanonInst alone does NOT
provide canonical kappaI. The two inputs have been used separately.

5. Define E_H(a,b) by the sum (HW.1) in main.tex, with coefficients
2 and 4, the strict exceptional condition Sigma>x^(-eps), and the
literal candidate set. The preceding steps identify it with WReq's sum.
WeightVectorExists supplies a,b in the two finite boxes. Outside T each
box coordinate is the singleton {0}. On T its integer endpoints are
  ceil(a0) <= a(t) <= floor(a0+a0/(k x^13)),
  ceil(b') <= b(t) <= floor(b'+2n delta x^eps Lambda b'/k),
where a0=s.a and Lambda=G.La(K,s). For an integer z,
ceil(u)<=z<=floor(v) is equivalent to u<=z<=v. Therefore these exact
boxes give WinOK and zero extension, and E_H<=x^-9 gives WOK.
These newly selected functions need not be the old point's actual aT,bT.

Conversely, suppose the point is From this particular host pair and
both functions vanish off T. On T the From degree equalities identify
the pair with aT,bT; off T both zero extensions vanish. Thus G.aL=a and
G.bL=b everywhere. The same E identity converts host WOK into WReq on
the point's ACTUAL degrees. Its windows follow from WinOK or Val.mem_box.
Together they give admW, which is precisely WallPt.

HW2. HOSTWW'S SELECT-THEN-REBUILD CONSTRUCTION
--------------------------------------------
6. The temporary family. Choose a host and an arbitrary initial pair
in its windows, with zero outside T, and an admissible common word code.
For each u0<n invoke the point constructor for this same pair and code.
Paragraphs 8--10 below prove that these points form a Kit. Doing this
at every sufficiently large scale and using the supplied NumAt records
gives the temporary family through the explicit constructor in HW3.
It satisfies the given hypotheses of GW5. The family has fixed eps,J
and constants; hence GW5 supplies one eventual threshold, before x and
the member index are chosen.

7. At an allowed scale above that threshold, Ix_win gives an actual
temporary point. GW5 gives WeightVectorExists for it. HW1 transfers the
new pair to the original host attached to its kit, preserving WinOK and
WOK. The scale is exactly the desired s: its x coordinate, eps and J
agree, and those three parameters determine Scale. All other host
properties are properties of the same original host. This proves the
degree-choice portion of HostWW, not an independent host existence
result. Apply the point constructor AGAIN, now keeping the selected
pair fixed for every u0<n. This second use is justified by the universal
pair quantifier of ObjC/ObjCP; it is not a coverage property of the old
family and is not a modification of its existing points.

8. The exact Same fields. Two reconstructed points have identical scale
and are From the same H,a,b,code. Their R,T,T2,q,d,g,pde,pde' and all
hP value labels agree directly. Underlying HostAx preservation gives
QS, artNum and rdE. Val gives the common Sc and eta. CanonInst gives
the common bs under value relabeling. For the entire kappaI function,
not just its values at actual degrees, k,s,Sc determine identical cG,
DIf,c6f,tIf and hence identical universal deficit sets. Extra.kapI_def
equates their infima. Extra.ep_def gives, for every natural number p,
  ep(p)=ceil(C.cX.Ce * R.f * R.k^2 * log_p(s.a))_Nat,
so these functions agree as well. For p>=2, log_p(a)=log(a)/log(p);
the source totalizes this to zero at p=0,1, so ep(0)=ep(1)=0.
Actual top degrees agree because
they are the same a,b at the unique common value label.

9. The offsets require the actual filling condition. For 1<=j<=m,
put i=j-1. Choose any finite place of the point's number field and
the Hodge index corresponding to tau1(t). Such a place exists: the
ring of integers is not a field, and a maximal ideal is nonzero.
The supplied ta.fills equation at this place is
  fill(j,(false,t)) = w_j(tau).
Val.hc says the adjacent profile has b_i=b1+i h0 and e_i=b_i+h0/2;
the actual w_j is e_(j-1). If t is a top, b1=bT(t)+floor(b'/x),
whereas fill=bT(t)+off. Cancel bT(t). If t is not a top, tau1(t) is
thin: it lies in the prescribed half of places, misses the top image
by injectivity, and misses the opposite thick image. Then
b1=ceil(s.w''(n)) and fill=off. Both cases give (HW.4), where the main
text writes w''_n=s.w''(n)=b'/(xn), a function evaluated at n.
The formula depends only on the common scale, ranks and T. At j outside
the lifts, CanonInst.2 gives b'/x on T and s.w''(n) off T. Thus every
required off(j,(false,t)) equality holds. No equality of arbitrary
Boolean-coordinate offsets outside Pt.Same's stated range is claimed.

10. Now take Kit.Ix=Fin(n), with point P_u at index u. It is nonempty
because n>0. Paragraphs 8--9 give the complete literal Pt.Same record.
Each point has a word equivalence eW to the same Fin(M) and its word
bits are c(eW(word)); equal labels therefore give equal codes.
The point at index u0 has distinguished position u0 by Pt.From, giving
Kit.cover. The Same degree fields also prove Kit.cover_weights. Every
point retains its supplied Q. HW1's reverse implication gives actual
WReq at all of them; the exact windows give admW=WallPt. This is the
degree-realization portion of the source's KitS construction.

11. Uniformity. When two suppliers have lower thresholds for cD, take
their maximum BEFORE selecting cD. Next do the same for ch thresholds;
then fix ch and take the maximum of the scale, initial-window and code
thresholds. All of these choices precede the scale and its host/member.
Build the temporary family, obtain GW5's single threshold for it, and
enlarge the final scale threshold. The selected pair may then depend on
the scale and host, while all u0-points use that same pair. Applying the
constructor twice adds no degree-dependent threshold because its
original quantifiers are universal in the pair. The nested order agrees
with HostWW and KitCPW. No quantitative bound for an unexpanded host or
point-construction threshold is being asserted.

HW3. THE ACTUAL FAMILY CONSTRUCTOR AND CHOSENWS
---------------------------------------------
12. To define a family at every real x while supplying kits only in an
unbounded window, choose one allowed y>=x1. Let s(x) be the actual scale
at x if x>x1 and x lies in the window, and the scale at y otherwise.
This is the source cutScale. Its kit is always defined. Set
  Ix(x)={i in kit(s(x)).Ix : x<=x1 or x is in the window}.
For x>x1 outside the window this index set is empty; in the window it
is nonempty. This supplies Ix_win and permits a harmless index at zero.
At every existing large index, s(x).x=x, s(x).eps=eps and s(x).J=J.

13. The famOfKits definition literally copies D,L, Gx,Gy, gatT, X,
ties, fills, lattice/tie records and Extra from the corresponding point.
The supplied NumAt supplies parameters, sizes, rho and the declared
constant identities. The common R,T,prime,Sc,eta,bs,off,kappaI,ep fields
are the proved Kit.same equalities; the common word system is Kit.eW.
The common bTop is bTopOf of one kit point. It is independent of that
choice because bTopOf depends on the shared scale,ranks and LaG, and
Val.La_eq gives the same G.La(K,s). The bound on each actual bT is the
supplied NumAt.bT_le. Kit.cover_weights supplies FamCore.coverS.
This verifies the constructor transport without proving the numerical
or geometric fields supplied by NumAt and Pt themselves.

14. Every constructed point has WallPt, so every family member has admW
on its actual degrees. Its loss expression differs from ChW_at only in
writing 2*(if E then 1 else 0) instead of (if E then 2 else 0).
These are equal in both Boolean cases. Thus beyond x1+1 every index
satisfies ChW_at: exactly ChosenWall. The source DesignS transports the
same point predicate through exists_famP_of_kits. Its final setTu changes
only the separate CTu bound and leaves this assertion unchanged.

15. Given any x in the window beyond max(xWall,x1+1), choose an actual
i0 from Ix_win. For each integer label t in the common TTn(x), there
is exactly one top of i0 with that value; transfer its aT,bT to av(t),
bv(t), and put zero off TTn. The actual aT window and bT lower bound,
together with the family's bT<=bTop, show the required admissibility.
The point i0 itself carries the pair. Every other carrier satisfies
ChW_at because ChosenWall applies to EVERY index, independently of the
carrier predicate. These are exactly all clauses of ChosenWS.
Even coverS is unnecessary for this last existential implication; it
can subsequently move the distinguished position preserving the pair.
