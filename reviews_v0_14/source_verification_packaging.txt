PORTABLE RERUN

A separate source_verification_v0_14_audit_portable.py is supplied. It takes the
artifact root from its own review-directory parent and adds --repo,
--verification-dir, and --output-dir. The substantive source-checking body is
identical to the historical script, apart from allowing parent-directory
creation for the fresh verification destination. Its changes are confined to
path/argument handling and rerun report identification/paths/date. It never
writes to the packaged report or other historical evidence.

From the extracted v0_14 directory, run with Python 3 and Git:

  python reviews_v0_14/source_verification_v0_14_audit_portable.py \
    --repo /path/to/lean-source \
    --verification-dir /path/to/new-source-verification \
    --output-dir /path/to/new-source-verification-results

The Git repository must contain commit
7cbf7a0c32fca1badf05931879a37c3f8a2b03b4, have HEAD at that commit, and have a
clean tracked worktree. A sparse checkout is sufficient if all needed Git
objects are locally available; a partial clone may fetch missing objects.
The script does not alter the checkout or build Lean. Both destination
directories must be new or empty, outside the artifact and repository, and
must not contain one another. Existing nonempty directories are rejected;
nothing is deleted or overwritten. If --output-dir is omitted, the result
directory is named by appending _results to the verification directory name.
The default --repo is a sibling lean-source directory. The default verification
directory is a sibling source_verification_v0_14_rerun directory.

Portable-script validation at packaging: Python syntax parse PASS; --help
PASS; entire substantive checking body compared with historical original
PASS. Source checks were not rerun for this packaging-only change because
the original completed audit remains the evidence and the merged source
inputs are unchanged. A later execution produces a separately dated report,
JSON and log. Neither the audit nor its portable derivative compiles Lean,
replays its kernel, or proves the overall mathematical claims.
