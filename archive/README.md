# Earlier research rounds

The [project history](project-history.md) records the successive working statements, checkpoints and mathematical deductions. In [rounds](rounds/), choose a version such as [v80](rounds/v80/) or [v90](rounds/v90/) to see the proof notes, registers and verification tools for that stage. The [older editions](editions/) and [supporting records](records/) preserve earlier reading copies and research material.

The [path map](path-map.tsv) gives the present location of each former top-level entry. For a path inside an old directory, replace its first component with the mapped path and keep the remaining components. In a historical source, a reference to a sibling directory uses the layout of its time. The [research guide](../research/README.md) explains how to recreate those paths from a current checkout, run the original scripts and bring fresh work back.

Existing citations to a specific public commit keep their original paths. The [public reconstruction immediately before the reading editions](https://github.com/bmatschke/grh-alpoge-claude/tree/f6918dbf16a8d5f4f86146fd9fa2c04efff4f8ad) gives an additional fixed point of reference.
