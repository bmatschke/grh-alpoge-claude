Continue the detailed human-readable reconstruction of the accepted

8. HOW TO WORK EFFICIENTLY WITHOUT LOSING READABILITY

Keep the old detailed proof-note style: stated hypotheses, explained
constructions, intermediate calculations and a clear final consumer.
The user strongly prefers that style to a short restart or an outline
that replaces arguments with labels. Simplifications and classical
theorems are welcome when their hypotheses are checked and an explicit
dictionary proves the full original target on the actual objects.

Start with the original consumer, read its producer body, and match each
immediate input to the current human ledger. Select the first missing
substantive construction. Call-site specialization can prevent needless
generality, but label a specialized result honestly; it cannot close a
broader original contract without the remaining scope being supplied.

For each new component, provide complete main.tex proofs, fresh claim
IDs, exact source locations and hashes, inherited inputs, retained
premises, contracts/closure metadata, a report and a next-source handoff.
Use existing v0.57 components as templates. Freeze the proof for a
different agent's mathematical and exact-scope review, then bind the
review to the corrected final text. Review common objects, quantifiers,
all primes/zero cases, measures and convergence before accepting joins.

The coordinator integrates only reviewed work, preserving earlier
proofs and keeping every dependency resolvable. Do not use a count of
claims, a successful TeX check or a conditional wrapper as evidence of
whole-obligation closure. Record exactly which original theorem is now
proved, which next consumer it supplies, and what still remains.
