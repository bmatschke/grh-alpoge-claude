PRIMARY ROUTE: SELECTED HOST PAIR, NOT FULL WEIGHT COVERAGE

The active construction is HostWW -> KitS -> DesignS -> ChosenWall -> ChosenWS.
CoverAll is a different, stronger sufficient condition and is not required by
this route. The current v0.11 HW1–HW3 component reconstructs its elementary
point/host/family transport under supplied construction records.

1. TOPS: ADD THE ACTUAL BIASED COSET SHARE CONDITION

GII9–GII10 prove uniform-Bernoulli cardinality and bad-orbit estimates. The
actual host also requires Frame.Shares, which prescribes proportions
4/(3o+1) in A0 and 3/(3o+1) in each other A0-coset. Thus the source chooses
independent probabilities delta on A0 and 3delta/4 outside A0. The next
substantive finite task is topsGroup: extend the conditional orbit bounds to
these nonconstant probabilities and obtain simultaneous concentration of all
coset counts together with the weighted bad mass. It invokes orbit_terms,
select and shares_of_counts. topsFrame and topsBase then identify the literal
frame and host parameters. This is genuinely additional to GII9–GII10.

The general character-host route is topsChoiceH -> ShortNorms.hostOfFieldOf
-> CharacterBoxes.hostOfField/supplyOfAdm. The hostOfFieldOf proof chooses TT
at line 218 and installs {D with TT:=TT} at line 223, preserving HostAx.
Its separate inputs include ShortNorm, SmallOne, PairGood, FieldRows and
HostParam.Seam.admitted; these have not been reconstructed by GII. The older
HostExistenceOfChoices.exists_hostGood is a useful ordinary cyclic-frame
specialization, not a substitute for this general host route.

There is no declaration literally named HostBadOK at this pin. The actual
record is GlobalTheory.EX.BadOK, a conjunct of HostGood. BadCharacterBound
transports it to ChBad_at using Pt.From and CanonInst. Exact preserved data:
rank, TT value image, q,d, prime classification, every Frobenius step value,
and the canonical orbit representative. Frame.Shares remains separate.

2. DEGREES: WREQ -> HOST WOK -> RECONSTRUCTED ACTUAL WEIGHTS

WindowShareRequirementClosedFormProof.w_of/wClosed supplies the source
DC.WClosed = eventual WeightVectorExists on a supplied FamP. Its substantive
finite averaging input is now GW5 (with GI/GII/GJ suppliers), so no new
prime-number estimate is needed for this portion.

HostWW starts from HostExQW and the point-construction interface ObjC. It first
builds a provisional kit at some admissible pair, packages it as a family,
applies WClosed, and extracts one newly selected pair. The lemma
weightWindowRequirement_host_of_point transfers the selected point functions
back to the common host; the comparison is exact because sig_eq_loc identifies
canonical kappa infima, candidates and orbit selectors. This gives host WOK.
KitS then invokes ObjCP again for that fixed chosen pair and each u0<rank.n.
The reverse wreq_of_wok transfer makes every reconstructed point's ACTUAL
weights satisfy WReq; its window clauses give WallPt=admW.

The next substantive construction inputs are therefore HostExQW and the actual
point supplier ObjC/ObjCP (Val, HostArith, From, CanonInst, requested geometric
properties), plus NumAt supply. Do not silently treat KitS or DesignS as proving
those inputs. HW1–HW3 only closes the transport/constructor join once they exist.

3. FAMILY ENDPOINT AND OPTIONAL COVERALL BRANCH

ExistsFamPOfKits.famOfKits copies the point records and NumAt fields into FamP;
its index set is the kit index restricted by x<=x1 or x in the common window.
Its coverS field is precisely Kit.cover_weights: move u0 while retaining the
same pair. DesignS propagates WallPt through its classOf transport and builds
ChosenTT/ChosenBad at lines 86–87. WeightAdmissibleSmallSharesAtPoint converts
admW to ChW_at (only an indicator coefficient identity); DutySevenLibrary then
exports ChosenWall. WeightVectorSmallSharesEight.chosenWS_of_wall realizes a
pair by choosing an existing member and copying its actual integer weights.
It uses Ix_win and the member's actual windows, not CoverAll.

A repository-wide exact-token search found FamCore.CoverAll's definition and
consumers, but no named constructor for it. This does not diagnose a gap in
the active route: Kit.same fixes the pair and KitS varies only u0; full coverage
is not its intended output. GW6's CoverAll implication remains a valid optional
route, but it should not become a mandatory continuation target.
