1. DIRECT FORMS0 FIELD CHECK

The source Forms0 structure has exactly atT, cls0, val0, gl, gl_K,
glev0, lv0, fMe0, fv0, up_natural_level_zero, down_natural_level_zero,
norm0 and bw0. FC19 identifies a supplier for every field with the same
objects throughout. In particular it constructs Forms0 itself, rather
than claiming that a partially constructed FormsTiedSym can already be
projected to Forms0.

The unique step-zero chart gives a bijection from the original class set
to its subtype fiber, c |-> (c,chOf(c)=beta), whose inverse is projection.
clsOfChart retains the actual chart level, y and stabI. All class-bijection,
carried-lattice, stabilizer injectivity and exact-range fields therefore
restrict along this same bijection, with no representative replacement.

The determinant witness for val0 is C=I in SF2's actual coordinates. It
preserves the original determinant label, not merely an abstract frame.
The FiC restriction equivalence uses surjectivity of the same class map;
evaluation on every class proves both directions. CV9's rational field
is unchanged and its local-integral criterion holds at every coefficient
prime. To recover the global integral field, the ideal

  b_x = { a in O_L : a*x belongs to M }

is proper if x is outside M. A maximal ideal containing it is one of the
coefficient primes. Membership in that localization supplies a denominator
outside the prime with a*x in M, a contradiction. Finite expressions in
the localized span supply that denominator by multiplication. This is
valid for an arbitrary O_L-submodule of an L-vector space; it does not
assume a free global lattice. FC7 supplies the exact ipV field and FC18
supplies both dil and dilT. These are precisely valOfG's inputs and fields.

The one common G from FC13 is chosen independently of u. Its piG identity
and supplied X.piG_K give gl_K; FC15 supplies GLev with exactly
(k,t,0,k,N0,false), including the same identity local frame. FC5's lvOfG
retains pr/prk, all kernel/surjectivity/linearity fields and te. FC6's
fMe0/fv0 uses the same residue equivalences and actual normalized functional.

The upOfG/dnOfG conversions take NB7/NB8 and discard only the automatic
chart equality in the singleton case. Their gamma, eta, kappa, support,
adelic relation, integral-local lattice identities, projection equations
and exact frame scalar remain unchanged. normOfG and bwOfG substitute the
identical eY, using FC7 and FC17. No period, terminal row, symmetric
penultimate group or terminal incidence field is needed for Forms0.

2. ACTUAL LEVELDATA AND JOINT0

I read the full exists_reindex and exists_colLevel proofs. Although the
latter theorem accepts FormsTiedSym, every occurrence of its parameter is
through its cls0 (written F.cls at zero), gl and glev0. Consequently its
proof is a genuine constructor from the step-zero data already built.
This is an extraction from the proof, not an application requiring an
unavailable full record.

The same rank identity r:k=N0 transports StepLevel and all class/stabilizer
matrices. The auxiliary-prime condition follows from the actual FC15
upper-unitriangular description; the required prime above g(0) exists by
lying over. Stabilizers preserve all completed class lattices. In a local
basis, a rational vector belongs to the completion precisely when each
rational coefficient has nonnegative valuation, equivalently when it
belongs to the prime-local lattice. LP1 then recovers the actual global
lattice. The same argument for the inverse gives preservation in both
directions. Thus the additional stabI_lat field is accounted for.

Every remaining ColLevel field is either a retained StepLevel field or
a transported class/stabilizer field. Choosing these independently for
each word gives exactly LevelData, whose definition imposes no hidden
cross-word equality. The construction additionally preserves the common
splitting G.sp and the identity-frame reindexing explicitly.

FC.40 has exactly the five SameCar fields, in the source orientation up
to symmetry of equality: base lattice; image of each local group; image
of the global group; each class matrix; and each stabilizer matrix. The
source definition of Joint0 is exactly this SameCar statement. No full
CarH, CarT, Joint or ColsTiedSym is needed. Functional normalization does
not alter any of these five objects.
