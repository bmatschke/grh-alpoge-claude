Outcome
-------
CZ1–CZ6 prove both original source predicates UpperTheory.V.HV.PropZ and
UpperTheory.V.HV.CountZ. In CountZ the uniform exponent is C=0; the
underlying length is actually zero. This is a complete supplier of one
of the five count premises used to build PointHV, not a conditional
wrapper around PropZ or around either residual-character case.

The proof is relative to finite global class field theory in explicitly
matched ray-class and Hilbert-class-field forms, together with ordinary
elementary number-field and finite local-ramification background. No
project-specific input remains in this component. It uses neither local
duality nor Poitou–Tate, neither LemmaK nor an automorphy or host-rigidity
statement, and no Bernoulli-unit vanishing theorem.

Complete chain
--------------
CZ1 identifies the actual discrete tensor module
O tensor_(Z_l) (Q_l/Z_l), the original negative cyclotomic action, and
the source restriction-kernel conditions. It proves that every continuous
cohomology class is l-primary torsion and that every l-torsion class has
a representative with values in M[l], by an explicit divisibility and
coboundary adjustment. Thus it suffices to kill l-torsion classes; the
argument does not presume finite generation or finiteness of the Selmer
group it is trying to prove zero.

CZ2 proves surjectivity of the actual cyclotomic character on inertia at
each original l-adic place, first at finite levels by Eisenstein total
ramification and then at the infinite level by nested compact fibers.
It also proves unramifiedness away from l by lifting prime-to-residue-
characteristic roots of unity in unramified extensions. Finite rational
class field theory places every unramified-outside-l additive M[l]
character in a finite cyclotomic layer of the original algebraic closure.
Finally, it proves the exact needed Selmer restriction injectivity by a
direct cocycle calculation: once a class is zero on the cyclotomic
kernel, its values depend only on the cyclotomic character, and the
single l-adic local coboundary witness then works globally.

CZ3 constructs the actual quadratic field inside the original algebraic
closure by a finite Gauss sum. It evaluates the product of the two Gauss
sums explicitly, obtaining tau^2=l when l=1 mod 4. The order generated
by (1+tau)/2 has prime discriminant l, so the discriminant index formula
shows it is the full ring of integers. The class-number bound h_K<l is
proved from scratch: the two-dimensional lattice diamond gives a small
ideal representative; at each rational prime the ideal count is bounded
by the divisor function; the harmonic-sum estimate and log X<X−1 finish
the inequality. A finite l-torsion unramified character of this actual
G_K factors through its ordinary ideal class group and must vanish.
Real-place inertia is killed because l is odd, so there is no silent
replacement by a narrow class group.

CZ4 handles l−1 dividing e. The residual coefficient action on M[l] is
trivial, so an l-torsion representative is an additive character. Local
conditions make it unramified outside l, and CZ2 kills its restriction to
the cyclotomic kernel and then the original global class.

CZ5 handles l−1 dividing 2e but not e, with e even. These congruences force
l=1 mod 4 and the residual character to be quadratic. Choose a single
inertia element delta with nonsquare cyclotomic reduction. Because
alpha(delta)−1 is a unit, normalize the cocycle by c(delta)=0 without
leaving M[l]. At every l-adic place, an inertia element with the same
cyclotomic value forces l times the local coboundary witness to vanish.
Only after this local calculation does the restriction to G_K become
zero on decomposition groups above l. It is unramified everywhere else,
so CZ3 kills it. The index-two coset and c(delta)=0 then kill the original
cocycle. This closes the full residual-quadratic vanishing argument.

CZ6 joins these two alternatives into PropZ for all its original data.
In CaseZ the character is trivial, 3 lies in the excluded prime set,
and character parity makes the positive twist even. Thus PropZ applies.
The stricter level-lN Selmer conditions only shrink the group. Both
Vlen and Vn are zero, so the literal VLe inequality holds with C=0,
chosen before all hosts, cutoffs, fields, coefficients and twists.

Bindings and simplifications
----------------------------
The output keeps the given Omega and O. The quadratic field is an
intermediate field constructed inside this Omega. Every local inertia
or decomposition restriction is taken on the original valuation groups.
The finite-place conditions used are contained in the source's full
valuation-family conditions, so proving the larger finite-place Selmer
group zero suffices for the literal source group. No claim is made that
every abstract valuation subring represents an additional finite place.

The direct cyclotomic-inertia argument replaces only the injectivity over
Q needed from the much stronger source control theorem. The proof does
not assert reconstruction of the full general-number-field control
theorem or its range statement. Likewise the normalized l-torsion
argument replaces the source's longer bounded-cocycle ShaToShT route;
it proves the required vanishing and does not claim all its quantitative
variants. The source hQuad bound is replaced by an explicit two-dimensional
proof; no implicit class-number estimate is assumed.
