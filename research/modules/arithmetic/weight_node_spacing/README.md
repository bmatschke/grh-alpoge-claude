# Node spacing on the classical host

Adriazola’s classical specialization identified a failed spacing inequality. The original choice of size exponent supplies a single gap large enough for the block conditions. Its value affects each tail of the signed height. The claims below compute the change and bound the finite-place costs on the same numerical row.

| Claim | Result |
|---|---|
| [WNS1](../../../../manuscript/notes/arithmetic/WEIGHT_NODE_SPACING_ON_THE_CLASSICAL_HOST.md#claim:WNS1) | A single exponent chosen after the box exponent satisfies all four source block inequalities and the cubic node bound. |
| [WNS2](../../../../manuscript/notes/arithmetic/WEIGHT_NODE_SPACING_ON_THE_CLASSICAL_HOST.md#claim:WNS2) | The larger spacing preserves the classical node boxes, torsion condition, word order and single-shift smoothing estimate. |
| [WNS3](../../../../manuscript/notes/arithmetic/WEIGHT_NODE_SPACING_ON_THE_CLASSICAL_HOST.md#claim:WNS3) | The changes of the native head and tail degrees give an exact signed-height increment, uniformly in the word. |
| [WNS4](../../../../manuscript/notes/arithmetic/WEIGHT_NODE_SPACING_ON_THE_CLASSICAL_HOST.md#claim:WNS4) | Increasing the orbit budgets bounds the changes in the inert and auxiliary-prime entries of the classical finite table. |
| [WNS5](../../../../manuscript/notes/arithmetic/WEIGHT_NODE_SPACING_ON_THE_CLASSICAL_HOST.md#claim:WNS5) | The two signed partitions increase by explicit partitions, and corner-minor multiplication embeds the original polynomial lattice with saturated image. |
| [WNS6](../../../../manuscript/notes/arithmetic/WEIGHT_NODE_SPACING_ON_THE_CLASSICAL_HOST.md#claim:WNS6) | The Fock norm of the multiplication map and the changes of both hook products have polynomial logarithmic cost. |
