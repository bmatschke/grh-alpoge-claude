Recommended next global work is the original common-construction route,
beginning with the exact SelC.cols_of_witnesses coordinate constructor
and then the selected-realization/BWit packet. Its value is that every
proof is tied to the one object needed by several final inputs. In
parallel, the current analytic branch has a clearly bounded residual:
same-target boundedness/FinPair and smooth representatives with the
uniform Sobolev estimate. The rationality/OneMap/CoverField branch is
the next substantial shared arithmetic target after those actual data
are exposed. This is an expected-contribution judgment, not a proof of
mathematical minimality or an exhaustive Lean dependency enumeration.

Classify completed finite transports as B; keep producer existence C;
promote a named published input to A only after the actual hypotheses
and normalization are matched. An untraced typed equality or original
instance is a D issue in human understanding, not evidence against the
formal proof. In particular, nested GlobalArtinReciprocity/ray-field
matching must not be silently certified by the theorem's name, and
the existing top-level D register is not altered by this note.

Count obligations are independent parallel work. CCH now supplies the
selected h=0 full-block Choice and B2 on its SAME chosen g=0 Kap; the
ordinary/control, four Hida, same-J HasAut, first-order B1 and Raw
producers remain. RH still uses I/II/V; unrestricted Dirichlet GRH also
requires III. No global construction shortcut removes those producers.

Do not reopen the completed global assembly. Do not change the original
family, common selector, coefficient field, weak choices, phase or
normalization to make a remaining lemma easier. Each next chapter must
name its exact sufficient interface, then distinguish what it constructs
from what it still assumes. The source anchors below locate the work;
