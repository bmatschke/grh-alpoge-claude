# The odd-minus estimate on a CM host

For a twist $e$ the source uses the $c=(-1)^{e+1}$ eigenspace of the strict Selmer group, where $c$ is complex conjugation. Both proofs below treat the original CM field and every finite set of odd primes.

* OB1–OB8 use the character bounds and Jacobi annihilators, handle the primes dividing the field degree separately and obtain exceptional-prime coefficient $240$. [Proof and bound, OB8](main.tex#L756-L827) · [Claim provenance](provenance.json)
* ETS15–ETS18 use global duality, descent to the real subfield and the higher relative class number formula. For a host of degree $n$ and conductor $N$, the total through $1\le e<t$ is at most $(n+1)t^2\log(tN)$. The exceptional-prime coefficient in the source can therefore be zero. [Special-value proof](../../../../manuscript/notes/galois/EVEN_TWISTS_AND_RANK_THREE_AUTOMORPHY.md#claim:ETS16) · [Exact window conclusion](../../../../manuscript/notes/galois/EVEN_TWISTS_AND_RANK_THREE_AUTOMORPHY.md#claim:ETS18) · [Claims and source ranges](../../galois/even_twist_selmer/claims.json)

For $\mathbf Q(\mu_9)$ and $e=2$ the full odd-minus sum is $\log 13$. [Worked computation](../../../../manuscript/notes/galois/EVEN_TWISTS_AND_RANK_THREE_AUTOMORPHY.md#claim:ETS20)
